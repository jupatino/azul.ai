Azul — Your AI Agent

Blue-light calm, one conversation away
  • Conversational assistant — answers questions, remembers your name, and helps with tasks in Slack.
  • List files — shows what's in the dedicated skills directory.
  • Read files — displays the contents of saved files (up to 100 KB).
  • Write files — creates or replaces files in the skills directory (up to 100 KB).
  • Run basic commands — limited to pwd and ls.
  • Persistent storage — files created survive service restarts (bind-mounted to the host).
Note: Files tools are restricted to the designated directory only — no access to other container or application files.
